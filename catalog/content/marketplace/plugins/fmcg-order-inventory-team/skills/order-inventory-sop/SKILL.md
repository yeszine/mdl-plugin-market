# 订货库存协同作业手册

本手册定义「订货库存协同专家团」的标准流程与字段，确保每次订货决策可复算、可追溯。

## 一、约束确认单

| 约束 | 需要确认的字段 | 缺失影响 |
|---|---|---|
| 时间 | 订货截止日、到货提前期、分批次上限 | 无法排到货节奏 |
| 资金 | 可用资金、账期、后返比例 | 无法判断资金占用 |
| 仓容 | 可用库容、冷链容量、卸货能力 | 可能到货即爆仓 |
| 政策 | 起订量、返利档位、搭赠、临期条款 | 无法测算真实成本 |

## 二、需求区间表

| 品类 | 悲观 | 基准 | 乐观 | 关键假设 | 置信度 |
|---|---|---|---|---|---|

规则：

- 三档必须有实质差异，乐观档不超过基准档 1.3 倍，除非有明确增量来源。
- 假设必须可验证，例如「气温连续两周高于 30℃」而非「天气好」。

## 三、净需求校准

净需求 = 需求 − 可用库存 + 安全库存

可用库存 = 现有库存 + 在途 − 已占用

校准规则：

1. 临期批次优先冲减需求
2. 90 天以上库龄先停补
3. 在途按到货时间折算可用
4. 安全库存按提前期与波动系数计算

## 四、订单与调拨

订单必填字段：供应商、SKU、数量、单价、金额、下单日、到货日、收货仓、订单类型。

调拨必填字段：调出仓、调入仓、SKU、数量、运输方式、成本、预计到达。

优先级：内部调拨 → 厂商补货 → 外部调货。

## 五、风险复核判定

| 项目 | 阈值 | 超限动作 |
|---|---|---|
| 订货额占可用资金 | > 70% | 有条件通过，需分批 |
| 订货后周转天数 | > 45 天（短保 30 天） | 削减订货量 |
| 单品类占比 | > 40% | 结构调整 |
| 临期金额占比 | > 5% | 先清库再补货 |
| 后返占毛利 | > 30% | 提示回收风险 |

## 六、决策记录

每次订货决策留档五项：

1. 数据快照时间
2. 三档需求与最终采用档
3. 净需求计算过程
4. 风险结论与条件
5. 30 天后的实际结果与偏差

## 七、常见错误

1. 用厂商任务量倒推需求。
2. 忽略在途库存，重复下单。
3. 一边报损临期货，一边新订同品类。
4. 为冲返利档位超订，导致资金与临期双压力。
5. 订货方案没有责任人与到货时间，执行落空。
