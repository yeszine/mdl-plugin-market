# 经销商经营复盘作业手册

本手册供「经销商经营复盘专家团」使用，定义一次复盘从开工到交付的标准动作，避免每次重新发明流程。

## 一、复盘周期与问题定义

开工前锁定四要素：

| 要素 | 说明 |
|---|---|
| 周期 | 月度 / 季度 / 专项（如某品类下滑专项） |
| 基准 | 环比 / 同比 / 预算，至少选两个 |
| 核心问题 | 一句话，可验证 |
| 场景 | 管理层例会 / 厂商汇报 / 内部自查 |

核心问题示例：「解释 10 月出货额环比 −8%、净利率 −1.2pt 的原因，并给出 11 月追赶动作」。

## 二、数据清单

必需：

- 出库明细：日期、客户、SKU、数量、单价、金额、是否赠品
- 回款明细：日期、客户、金额、方式
- 采购/成本：SKU、单位成本、到货日期
- 费用明细：科目、金额、归属期间、归属部门
- 库存快照：SKU、数量、金额、库龄、批次

可选但显著提升质量：

- 门店主数据与活跃进货记录
- 退货、折让、返利结算单
- 厂商任务与返利政策文件

## 三、口径检查清单

- [ ] 出货额是否含赠品、搭赠、样品
- [ ] 退货是否冲减当期
- [ ] 返利冲收入还是计费用
- [ ] 库存是否含在途与残次
- [ ] 客户编码是否去重
- [ ] 期间按业务日期还是录入日期

任一项未确认，结论标注为「方向性」。

## 四、毛利桥模板

| 因子 | 计算式 | 本期影响 |
|---|---|---|
| 价格 | （本期均价 − 上期均价）× 本期销量 | |
| 成本 | （本期单位成本 − 上期单位成本）× 本期销量 | |
| 结构 | Σ（占比变化 × 各品类毛利率差） | |
| 其他 | 退货 / 折让 / 返利 / 运费 | |
| 合计 | 应等于毛利额变化 | |

## 五、增长质量判定

| 情形 | 判定 |
|---|---|
| 出货涨、活跃门店涨、退货率稳 | 自然动销增长 |
| 出货涨、新客户增加 | 渠道扩张 |
| 出货涨、活跃门店平、渠道库存涨 | 压货，低质量 |
| 出货跌、活跃门店跌 | 真实下滑，需查原因 |

## 六、报告结构

1. 结论摘要（三条结论 + 三项动作）
2. 目标完成度（出货 / 回款 / 毛利 / 净利）
3. 归因（毛利桥 + 结构变化 + 增长质量）
4. 风险与机会（按影响 × 概率排序）
5. 行动项（动作 / 责任人 / 时间 / 验收指标）

## 七、行动项验收标准

- 每条动作必须能在一个复盘周期内验证
- 验收指标必须是可取的数，不能是「提升意识」
- 责任人必须是岗位而非「大家」
- 超过 3 条动作时，按对利润的影响排序，只保留前 5 条

## 八、常见错误

1. 先算数再定义问题，导致分析很全但没有结论。
2. 用总额增长掩盖结构恶化。
3. 把厂商压货计入自身增长。
4. 归因到「市场不好」就停止，没有落到可执行动作。
5. 行动项没有责任人和时间，下次复盘重复出现。
