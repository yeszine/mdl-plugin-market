# S6 ERP 只读查询

本技能约束连接器 `fmcg-erp-readonly` 的调用方式。连接器只提供查询工具，不提供任何写入、审核、反审核、删除能力。

## 可用数据域

| 数据域 | 典型问题 | 口径提醒 |
|---|---|---|
| 客户 | 客户档案、区域、渠道、账期 | 以 ERP 客户编码为准，不按名称模糊合并 |
| 商品 | SKU、规格、箱规、品类、品牌 | 区分「基本单位」与「箱」，换算前先确认箱规 |
| 订单 | 订单日期、客户、SKU、数量、单价、政策 | 已审核订单才计入出货口径 |
| 出货 | 出货单、数量、金额、退货 | 退货单独列示，不直接冲减净销量 |
| 库存 | 仓库、批次、可用量、锁定量 | 可用量 = 现存量 − 锁定量 |
| 应收 | 应收余额、账期、逾期天数 | 以财务确认的应收为准 |

## 调用规范

1. 先确认时间范围、组织范围与口径，再发起查询。
2. 订单与出货分开取数：订单看需求，出货看实际履约。
3. 金额类结论必须注明是否含税、是否含退货。
4. 结果超过 500 行时先聚合，再按需下钻明细。
5. 任何情况下都不调用写接口；发现只有写接口能满足需求时，明确告知用户改走 ERP 人工流程。

## 输出建议

- 表格优先给出：客户 / SKU / 数量 / 金额 / 时间。
- 结论前标注数据截止时间与查询口径。
- 涉及应收回款时，同时给出逾期天数与账期，不只给余额。
