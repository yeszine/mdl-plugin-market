# 经销商经营看板 · 复现说明

这是一条模板案例，不是可安装的代码包。安装模式只有 `prompt`：把 `prompt.md` 的提示词连同依赖技能一起交给 AI。

## 依赖

- `mdl.skill.business-ops-analysis` 1.0.0
- `mdl.skill.html-report` 1.0.0

## 数据要求

| 文件 | 必需 | 关键字段 |
|---|---|---|
| 销售明细 | 是 | 日期、区域、客户、SKU、数量、金额 |
| 回款明细 | 是 | 日期、客户、回款金额、账期 |
| 库存快照 | 否 | 仓库、SKU、数量、库龄 |

## 复现步骤

1. 安装两个依赖技能。
2. 上传三张底表。
3. 粘贴 `prompt.md` 的提示词。
4. 按 AI 追问补充口径（含税/不含税、退货是否冲减）。

成品示例见 `preview.html`，缩略图见 `cover.svg`。
